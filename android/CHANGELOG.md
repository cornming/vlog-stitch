# 更新紀錄

格式說明：每個版本一個 `## v<versionName>` 區塊，底下的內容會自動變成 GitHub
Release 的說明文字，App 裡的「檢查更新」和「更新紀錄」讀的就是這段。

## v1.0.0

第一個可安裝的版本，先確認基本流程走得通。

- 多選影片，可調整順序、移除
- 用 Media3 Transformer 接成一支 mp4，走系統的硬體編解碼器
- 規格一致時自動只做轉封裝，不重新編碼
- 成品直接存進相簿的 Movies / vlog-stitch，不用再下載
- 內建檢查更新與更新紀錄，有新版會跳出說明

尚未實作：裁切頭尾、字幕、背景執行。先驗證安裝與匯出沒問題再往下做。
