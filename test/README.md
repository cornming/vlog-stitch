# 測試

用**真的影片檔**驗證 `index.html` 裡的匯出引擎，不用假資料。

```bash
npm install
./run.sh
```

## 做法

`run.sh` 直接從 `../index.html` 把主程式抽出來，接上 Node 版的 mediabunny
（`@mediabunny/server` 提供編解碼器），再用 ffmpeg 產生的測試影片跑完整流程。
測的是實際會上線的程式碼，不是複製一份。

測試素材是三段同規格的 1080x1920 / 60fps / H.264 + AAC，各自用 300、600、900Hz
的音調。這樣可以用頻譜直接驗證**接續順序**和**聲音同步**——某個時間點聽到哪個
頻率，就知道播到哪一段。另外一段 `odd.mp4` 規格刻意不同，用來驗證自動退回。

## 涵蓋範圍

- 快速接片、重新編碼，有裁切與無裁切
- 規格不一致時自動退回重新編碼
- 單一片段、帶字幕
- 輸出長度、串流組成、音畫同步（`checkfreq.py`）

## 測不到的部分

Node 沒有 `VideoFrame`，所以 `drawWithFit()` 畫不出實際畫面，重新編碼模式的
成品是黑畫面。影格數、時間戳、聲音、長度都是真的，只有畫素內容驗不了。
字幕繪製要另外用 `@napi-rs/canvas` 輸出 PNG 目視確認。
